# Mike & Rachael — Start your Treasure Journal

**Author Sign In:** https://aladdinslamp.xyz/journal/author.html

This is your Aladdin's Lamp entrance. Select **Continue to Writing Desk**, and verify with your authorized email address if prompted. You do **not** need a Cloudflare account or GitHub access.

1. Select **New Story** in the private Writing Desk and enter your title, category, and short introduction.
2. Write paragraphs and upload photographs from your device. Use **Add photo in story** to place them between paragraphs; use up/down controls to move them, and add captions.
3. Select **Preview** and check your work. When online, drafts save automatically; look for **Saved securely**.
4. Only after the article is ready, select **Publish online**, confirm, and share it on Facebook or using the story link.

**Public Treasure Journal:** https://aladdinslamp.xyz/#journal

**Important:** The public Journal is for readers and does not request a login. The author entrance is separate so visitors cannot view drafts. Cloudflare Access remains the secure email-verification gate protecting the private Writing Desk. If access says your account is not allowed, ask the site administrator to check the existing authorized-email policy.

The former GitHub JSON story composer at `/journal/write.html` is retired. Never publish by editing repository JSON or sharing login credentials.

**First test:** Create a short draft, add one photo, preview it, and confirm that it saves before publishing a real article.
